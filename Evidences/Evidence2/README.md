# Evidencia 2 - Estructuras de Datos Lineales

## Descripción
En esta evidencia hice un programa en C++ para leer registros de eventos, ordenarlos con MergeSort, buscar por fecha y mostrar estadísticas. Utilicé Queue, DoublyLinkedList y Stack, que ya habíamos trabajado en clase.

## Cómo ejecutarlo
El programa se compila desde la terminal de VS Code con g++.

Compilación:
`g++ evidencia2.cpp -o prueba_final.exe`

Ejecución:
`.\prueba_final.exe`

Al iniciar, se elige uno de los dos archivos (`log607-1.txt` o `log607-2.txt`) y después se utilizan las opciones del menú.

Para buscar una fecha, el mes se escribe abreviado en inglés, por ejemplo, `Sep`.
